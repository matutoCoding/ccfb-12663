# 注塑充填仿真(浏览器端)

精密注塑模具充填模拟工具:TypeScript + WebGL2,全部数据保存在浏览器本地(IndexedDB),无需服务器。

## 快速开始

```bash
npm install
npm run build     # 编译 TypeScript 到 dist/
npm run serve     # 启动静态服务器 http://localhost:8080
```

打开 http://localhost:8080 即可使用。

## 功能

- **项目列表**:项目新建/复制/删除,改动自动保存(IndexedDB);方案可打包导出为 JSON 文件,同事导入即可查看
- **方案编辑**:模型检查(破面/非流形边提示)、内置手机壳与盖板测试模型(无文件也能跑通全流程)、STL 导入
- **网格剖分**:WebWorker 后台剖分不卡界面,节点/单元数实时显示,细分级别 0–3 可调
- **浇口**:模型上直接点选,支持多浇口、单独开启时间、删除重设
- **充填计算**:Hele-Shaw 简化模型,三角网格控制体积法解压力场与流动前沿,充填时间等值云图 + 可变速动画回放
- **仿真任务**:进度与预估剩余时间、失败标红并注明原因、中途取消、同参数结果缓存不重算
- **缺陷预测**:熔接痕与困气自动标注,列表点击视角直接飞过去
- **材料库**:Cross-WLF 粘度模型参数、导热系数、固化温度等维护,改参数后同方案重算对比
- **方案对比**:充填时间/最大注射压力/锁模力等指标并排,差异超阈值标红
- **报告导出**:独立 HTML 文件,含云图截图与关键指标
- **设置**:默认网格精度、单位、对比阈值、动画速度;编辑操作支持撤销/重做(Ctrl+Z / Ctrl+Y)

## 关键设计

### 确定性(同参数两次运行结果完全一致)

- 求解器不使用随机数与系统时间,所有迭代按固定索引顺序执行
- 粘度定点迭代次数固定(2 次),CG 迭代次数只影响收敛精度不影响收敛路径(固定容差)
- 测试:`npm test` 中验证两次运行逐位一致

### 性能(10 万单元 < 30 秒)

- 流动前沿用动态列表维护,每步只扫前沿节点(约 √N),不扫全场
- 压力场用 Jacobi 预条件 CG 求解,热启动(上一步解作初值),粘度滞后标量近似
- 压力场每批节点充满后才重解(上限 200 次),统计量只在重解时更新
- 网格剖分与求解都在 WebWorker 中,主线程不卡

### 物理模型

- Hele-Shaw 等温近似:q = (w·h³/12μ)·Δp/L,控制体积法装配
- 粘度:Cross-WLF 模型 μ(T,γ̇) = μ₀/(1+(μ₀γ̇/τ*)^(1-n)),μ₀ 由 WLF 方程给出
- 熔接痕:相邻节点几乎同时充满且来流方向相反
- 困气:后半程局部最后充满点

## 目录结构

```
src/
  types.ts       共享类型
  solver.ts      Hele-Shaw 求解器(纯 TS,Worker 与 Node 测试共用)
  geometry.ts    STL 解析、网格检查、细分、内置模型
  render.ts      WebGL2 渲染器(云图/动画/拾取/视角飞行)
  store.ts       状态中枢:自动保存、撤销重做、任务队列、结果缓存
  db.ts          IndexedDB 持久化
  workers/       网格剖分与求解 Worker
  ui/            各页面(项目/编辑器/任务/材料库/设置/对比/报告)
```
