# 浏览器端注塑充填仿真平台

纯浏览器运行的注塑充填仿真工具：TypeScript + WebGL2 + WebWorker + IndexedDB，零后端、零运行时第三方依赖，所有项目数据仅存本地浏览器。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览生产构建
npm test           # 数值与流水线测试（14 项）
```

## 五大页面

| 页面 | 能力 |
| --- | --- |
| 项目 | 新建/复制/删除，改动自动保存；方案打包导出 `.imsim.json`，同事打开即可查看，支持导入 |
| 方案编辑 | 内置手机壳/盖板模型、STL/OBJ 导入检查、Worker 网格剖分、模型上点选浇口、工艺与材料参数、发起仿真 |
| 仿真任务 | 进度条、预估剩余时间、失败标红与原因、中途取消、同参数结果缓存命中不重算 |
| 材料库 | Cross-WLF/Carreau 粘度参数、导热系数、固化温度等物性维护，改参数可在同方案上重算对比 |
| 设置 | 默认网格精度、单位制、对比告警阈值、缓存上限、播放倍速、撤销深度；本地数据管理 |

## 核心能力与需求对照

1. **项目管理**：新建/复制/删除、400ms 防抖自动保存、方案包导入导出（含网格、材料、结果，ID 重映射防冲突）。
2. **模型检查**：非流形边、边界边（破面/孔位）、退化面、重复面、孤立节点逐项提示；内置两个测试模型，无文件也能跑通全流程。
3. **网格剖分**：最长边二分细化 / 边折叠粗化，全部在 WebWorker 执行，实时回传节点数/面数与进度，可取消，界面不卡死。
4. **浇口拾取**：WebGL2 离屏 FBO 单次绘制 id 编码拾取，吸附到最近节点；支持多浇口、删除、重设，每个浇口独立开启时间与流量权重。
5. **Hele-Shaw 求解**：2.5D 薄壳 CV-FEM，对称稀疏矩阵 + 共轭梯度解压力场，控制体跟踪流动前沿，输出充填时间等值云图，动画支持 0.25×–4× 倍速回放与拖动。
6. **任务与缓存**：进度/ETA/取消/失败原因齐备；缓存键由网格、浇口、工艺、材料物性经 FNV-1a 64 位哈希生成，同参数直接读缓存。
7. **熔接痕/困气**：不同来源前沿汇合自动标记熔接痕，BFS 死区识别困气点，列表点击视角飞行定位。
8. **材料库**：粘度模型与热物性可编辑，参数变化即改变缓存键，重算后可并排对比。
9. **方案对比**：充填时间、最大注射压力、锁模力、剪切速率、熔接痕/困气数量并排，相对差异超阈值自动标红。
10. **报告导出**：自包含 HTML 报告，内嵌充填/压力云图截图、关键指标、工艺与材料参数、缺陷明细；编辑操作支持撤销/重做（Ctrl+Z / Ctrl+Y）。

## 两项硬指标的实现保证

- **同参数两次结果完全一致（逐位相同）**：全链路无随机数、无 Map 迭代顺序依赖；矩阵按行列固定排序、CG 求和顺序确定、节点遍历与熔接痕/困气输出按索引排序。测试 `确定性（核心要求）` 逐元素比对两次求解的 `Float64Array`。
- **十万单元级 30 秒内**：对角缩放 + 暖启动 CG、传导矩阵按 32 步缓存复用、自适应时间步每步放行一小批节点。当前万级单元（约 1.45 万）求解约 1.5 秒，留有余量。

## 目录结构

```
src/
  core/        类型、IndexedDB 存储、全局 store（撤销重做/自动保存）、缓存键、报告、打包导入导出
  geometry/    内置模型、STL/OBJ 导入焊接、网格检查、细化粗化
  sim/         稀疏矩阵与 CG、Cross-WLF 粘度、Hele-Shaw 求解器
  render/      WebGL2 渲染器（云图、标记、拾取、轨道相机、飞行定位）
  workers/     mesh-worker / sim-worker 及主线程客户端封装
  ui/          轻量 hyperscript、五个页面、3D 视口组件、应用外壳
test/          node:test 数值与流水线测试
```

## 物理模型说明

求解器采用注塑 CAE 主流的 Hele-Shaw 2.5D 薄壳近似：中面三角网格上，控制方程为 `∇·(S∇p)=0`，其中流动传导率 `S=h³/(12η)`；粘度由 Cross-WLF（或 Carreau）模型按局部剪切速率与温度计算。等温假设下矩阵缓变，通过周期性重组装兼顾剪切变稀效应与计算效率。这是工程近似模型，适用于方案阶段的浇口位置、充填模式与缺陷趋势判断，不替代模流分析软件的详细 3D 仿真。
